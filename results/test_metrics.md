## Estimator: bias (E1), calibration (E3), accuracy (E4)

e = r sin(theta_hat - theta), positive = estimate above the drone. E1 uses one mean per run (runs are independent; ticks inside a run are not). Runs that share the same drone path and radar noise (one scenario flown from several turret start angles) give identical estimates, so they count once here: "Runs" = independent estimator runs (46 of 46). ## Estimator: error vs sideways acceleration (E2)

e = b0 + b1·a_perp, a_perp = true drone acceleration across the line of sight. b1 in m per (m/s²) = s²: a 20 m/s² turn shifts the estimate by 20·b1 m. The pooled OLS SE treats ticks as independent (too optimistic); the run-level t-test on per-run slopes is the one to use for conclusions.
